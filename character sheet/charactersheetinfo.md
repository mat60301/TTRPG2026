# Character Sheet — Information Spec

Two pages. Edit this file as the required fields change.

---

## Page 1

### Identity
- Character name
- Player name
- Species
- Level
- Class name (narrative label the player defines)

### Character Concept
- Origin story (1–2 lines)
- Ultimate fantasy / end goal (1–2 lines)
- Reason for adventuring (1–2 lines)

### Traits
All 12 traits, each with a **Value** slot and a **Die** slot (d4 / d6 / d8 / d10 / d12).

Grouped by category:

| Group            | Traits                          |
|------------------|---------------------------------|
| Physical Attack  | Strength, Speed, Finesse        |
| Physical Defense | Endurance, Balance, Toughness   |
| Mental Attack    | Knowledge, Wisdom, Charisma     |
| Mental Defense   | Willpower, Awareness, Empathy   |

### Derived Stats
Pre-calculated; update when traits or modifiers change.

- Physical Defense
- Mental Defense
- Physical Mitigation
- Mental Mitigation
- Resolve (current / max)
- Combat Speed
- Out-of-combat speed
- Resonance current / max *(magic characters only)*

### Class Modifiers
3 picks. Each entry should note the modifier name and any required specifics.

- Modifier 1 (e.g. "Weapon Training — melee, standard")
- Modifier 2
- Modifier 3

---

## Page 2

### Specializations
One entry per specialization. Each entry includes:
- Circumstance description
- Type: Combat or Role-Play
- Dice count (base = 2 dice; +1 die per additional specialization that stacks)

### Equipment

**Weapon(s)**
Each weapon: name, category, damage die, main-hand accuracy mod, off-hand accuracy mod, special notes (e.g. Brutal condition defined at acquisition)

**Armor**
Name, category, defense modifier, mitigation bonus

**Shield**
Name, size (Small / Medium / Large), Physical Defense bonus

**Charm**
Name, category, defense modifier, mitigation bonus

**Other gear / accessories**
Free-form list (cosmetic unless otherwise noted)

### Magic *(if applicable)*
- Magical Domain (description)
- Foundational Effects — each needs a name and a description of what it does

### Active Conditions
A few blank tracking slots for conditions in play.

### Notes
Free space.
