# Core Mechanics

## Design Principles
1. Players have more fun when they succeed.
2. Players have more fun when they actively participate.
3. Players enjoy rolling dice, especially multiple dice.
4. The risk of failure must be real in order to appreciate success.
5. Complexity is welcome; excessive amounts of rules are overbearing.

---

## Core Resolution
A player declares what they intend to do. The GM determines:
- Whether a roll is required
- The difficulty of successfully completing the task
- Whether the action requires a single roll or multiple rolls
- How long it may take to complete

## Core Roll
Unless otherwise noted:

**Roll: 1d20 + Trait Die + Trait Value + Modifiers**

The roll succeeds if it meets or exceeds the assigned difficulty. If it falls short, the roll fails.

> **On Failure:** Failure always produces a narrative result. The action may not achieve the player's intent, but something still happens. If a player throws a fireball and misses, the creature may be spared — but there's still a fireball hurtling through the room.

---

## Difficulty Benchmarks
These are tools for the GM. They do not scale with level.

| Difficulty | Target Number |
|------------|---------------|
| Very Easy  | 7             |
| Easy       | 11            |
| Average    | 16            |
| Hard       | 20            |
| Very Hard  | 24            |
| Impossible | 28            |

Tasks do not become harder as players level up — players simply encounter more difficult tasks.

---

## Repeated Attempt Penalty
If a character attempts to solve a problem and fails, subsequent attempts are penalized:

| Attempt | Cumulative Penalty |
|---------|--------------------|
| 2nd     | −5                 |
| 3rd     | −10                |
| 4th     | −15                |
| …       | −5 per attempt     |

The penalty applies when:
- The same trait is used
- On the same problem
- Without a meaningful change in approach

The penalty is tracked per problem, not per character. A failed attempt by any party member counts toward the penalty for all subsequent attempts by anyone. A group of four cannot simply pass a problem around and each try it fresh.

---

## Advantage and Disadvantage
- **Advantage:** Roll the d20 twice and take the higher result.
- **Disadvantage:** Roll the d20 twice and take the lower result.

When a character has both advantage and disadvantage simultaneously, count the sources of each. The side with more sources applies. If the counts are equal, roll normally.

*Example: 3 sources of advantage and 1 source of disadvantage — roll with advantage. 2 sources of each — roll normally.*
